## Mode

Operate.

## Task and success

Help merchants quickly enter an existing account or create a store, while
keeping account recovery, device verification, and one-time-password steps
understandable and easy to complete.

## Direction

Use the selected guided-entry composition: a compact Nalsh header, a clear
context statement, and a focused form panel. Keep each action easy to scan,
make account creation and recovery visible beside sign-in, and use the same
responsive frame for registration, OTP, and password recovery.

## Invariants

- Preserve the current light and dark theme colors and RTL behavior.
- Preserve authentication requests, saved-account actions, form validation,
  redirects, and loading/error states.
- Keep forms usable on narrow phones, tablets, and desktop screens; longer
  registration forms must scroll rather than clip.
